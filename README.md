# Fork AI

### Natural Language Analytics, Powered by AI

**Fork AI** is an end-to-end data engineering and AI analytics platform built on food delivery application data. It enables users to explore operational and business data using natural language. The system transforms questions into SQL, validates generated queries, executes them against a Snowflake data warehouse, and converts the results into clear, business-friendly insights.

**[🚀 Live Demo](https://fork-ai.streamlit.app/)**
